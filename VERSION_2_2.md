# Version 2.2 — Volume Mode

## Added
- Multi-mode gesture integration using `ModeManager`.
- Hold the volume pose for 0.7 seconds to enter Volume Mode.
- Thumb-to-index distance controls Windows master volume.
- Smoothed volume updates to reduce jitter.
- Automatic return to Normal Mode when the volume pose is released.
- On-screen mode label, volume percentage, and volume bar.
- Mouse cursor movement is suspended while Volume Mode is active.

## Volume gesture
Keep index and middle fingers raised, ring and pinky folded, and use the thumb with the index finger. Hold the pose briefly to activate Volume Mode. Move the thumb farther from/closer to the index finger to raise/lower volume.
